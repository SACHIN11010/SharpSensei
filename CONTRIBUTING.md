# Contributing to SharpSensei

Thank you for your interest in improving SharpSensei!

## 🚀 How to Contribute

1. **Fork the Repository** on GitHub.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Commit your changes**:
   ```bash
   git commit -m 'Add new WinForms practical simulation'
   ```
4. **Run Type Checks & Verification**:
   ```bash
   npm run lint
   npm run build
   ```
5. **Push to your branch**:
   ```bash
   git push origin feature/amazing-feature
   ```
6. **Open a Pull Request**.

## 🎨 Guidelines & Standards
- Ensure code passes type checks with `npm run lint`.
- Ensure components follow the modular layout in `src/components/`.
- Preserve existing C# WinForms lab educational logic.
